My project is called Level Ground Learning and it was made to create free tutoring for those who are less fortunate and cannot afford it around my North Jersey Area.
I made my project because I have tutored for free before online but I stopped because it was a huge challenge to get kids to pay attention through the screen. Therefore, I decided to make a tutoring service that is in person so that I can actually make a real difference in my community.
I made my project on VS Code Editor. I started with the homepage html followed by CSS and js. For every page, I would start with the HTML to get the overall structure, then the CSS to make it look pretty, and finally the JS to make it functional. After I created the homepage, I created a Get Involved page, followed by a Signup page, Meet the Tutors page, and lastly, a Resources page!
I struggled with attaching the CSS and JS files to the HTML, understanding how to commit through Git, and using proper JS to create a form. I didn't know how to connect CSS and JS files to the HTMl and when I looked it up, it still wasn't working because I did not have them in the same file. I did not know this so it was extremely frustrating. Next, I did not know how to commit from Git and it took me numerous videos and questions to finally figure out how and get GitBash. Lastly, I had a hard time with the JS in the signup section for my form, but after watching a lot of videos, I finally figured out when to use the 'else' and what to put in it
